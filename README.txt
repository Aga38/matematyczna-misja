INSTRUKCJA PUBLIKACJI – GitHub Pages

1. Zaloguj się na https://github.com i utwórz nowe publiczne repozytorium o nazwie matematyczna-misja.
2. W repozytorium wybierz Add file > Upload files. Prześlij WSZYSTKIE pliki z rozpakowanego folderu (nie sam plik ZIP). Zatwierdź przyciskiem Commit changes.
3. Wejdź w Settings > Pages. W Build and deployment ustaw Deploy from a branch, Branch: main, Folder: /(root), kliknij Save.
4. Poczekaj na opublikowanie strony i otwórz adres pokazany w Settings > Pages.
5. Adresy stacji będą mieć postać: https://TWOJ-LOGIN.github.io/matematyczna-misja/stacja-1.html (analogicznie 2–5).
6. Prześlij mi opublikowany adres strony. Przygotuję 5 kodów QR z logo sowy do wydruku.

UWAGA: Repozytorium i karty będą publicznie dostępne. Nie zamieszczaj danych uczniów.
